# 刷课保活 + 课程页章节列表

两件事都是真机验收项：**锁屏后视频不能停**、**课程页要看得见 91 章和当前正在刷哪一章**。

## 一、锁屏继续刷（唤醒锁）

真机取证：跑着课的时候 `dumpsys power | grep -i "wake locks"` 是 `Wake Locks: size=0`，
只有 `MonitorService` 这个前台服务在，CPU 一锁屏就睡 —— 视频协程和 WebView 一起停。

现在的做法（`StudyService`）：

| 项 | 值 |
|---|---|
| 锁类型 | `PowerManager.PARTIAL_WAKE_LOCK`（只保 CPU，不点亮屏幕） |
| 标签 | `<包名>:course-run`（`dumpsys power` 里一眼能认出来） |
| 获取时机 | `CourseRunQueue.start()` → 起 `StudyService` 前台服务 → 有课程在跑/排队就持锁 |
| 释放时机 | 暂停、队列跑完、`stopSelf`、`onDestroy`；另设 6 小时上限兜底 |
| 通知 | 标题「正在刷《课名》· 第 N 章」，正文是当前状态 + 任务点进度，带「停止」按钮 |
| 屏幕常亮 | 课程页在跑的时候给 Window 加 `FLAG_KEEP_SCREEN_ON`，暂停/跑完立刻清掉 |

`CourseRunQueue.State` 里新增 `chapterIndex` / `chapterCount`（视频阶段取
`StudyManager.state.doneChapters/totalChapters`，文档阶段取第 i 个/共 n 个），
通知和课程页都用这两个数说「第几章」。

### 锁屏验证步骤（真机）

1. 打开课程页 → 点「开始」，等日志出现「[课程] 已获取唤醒锁（锁屏后继续刷）」。
2. 双击通知栏确认刷课通知标题是「正在刷《…》· 第 N 章」。
3. 按电源键锁屏，计时 **60 秒**。
4. 解锁，进「日志」页看：
   - 视频阶段的 `[课程] 正在刷视频 x/y · 章名` 心跳（每 5 秒一次）在锁屏期间**没有断**；
   - `视频完成` 类日志条数比锁屏前增加。
5. 回课程页点「暂停」，日志出现「[课程] 已释放唤醒锁」，再 `adb shell dumpsys power | grep -i "wake locks"`
   应看到 `size=0`（或只剩别的 App 的锁）。
6. 对照命令：
   ```bash
   adb shell dumpsys power | grep -i -A3 "wake locks"
   adb shell dumpsys activity services com.xxt.sign | grep -i study
   ```

## 二、课程页章节列表

0604 那版课程页只有「任务点 189/392 · 48%」+ 一行状态 + 按钮，下面空着。

现在 `CourseActivity`：

- **数据**：体检结果 `CourseAudit.chapterRows` 为主，本地章节缓存（`StudyCourseStore`）补齐，
  **零额外请求**；两处都没有才真的空（并在日志里写明原因）。
- **每行**：章名 + 右侧状态（已完成 / 正在刷 / 未开始 / 未开放）。
- **高亮**：正在刷的那一章用主色 + 浅底，状态写「正在刷」。
- **自动滚动**：当前章变了才 `scrollToPositionWithOffset` 滚到可见（约屏幕 1/3 处），
  不跟用户的手势抢。
- **诊断日志**（只在内容变化时打一行，避免刷屏）：
  `[课程页] <课名> 章节列表 N 行（体检 M / 缓存 K），正在刷：<章名>`
  空的时候追加一行 `[课程页] 章节列表是空的：…课程 id=…`。

## 三、平台任务点口径（0/0 事故）

真机日志：`已完成任务点: <span style="color:#00B368">0</span>/0` —— 页面确实返回了 0/0，
老代码把它当有效值 → 分母从平台的 392 退回自数 213。

现在（`StudyApi.getChapterPage` + `ChapterPageUrl`）：

| 顺序 | 地址 | 说明 |
|---|---|---|
| 1 | `https://mooc2-ans.chaoxing.com/mooc2-ans/mycourse/studentcourse?courseid=&clazzid=&cpi=&ut=s` | 抓包里 11/392 就是它，四个参数缺一不可 |
| 2 | `https://mooc1.chaoxing.com/mooc-ans/mycourse/studentcourse?<同参数>` | 备用域名 |
| 3 | 主地址 + `&t=<时间戳>` | 防服务端缓存了一个 0/0 的结果 |

- `parseTaskPointTotals` 把 **0/0 当成没解析到**（返回 null）；`0/140` 是合法值。
- 三个地址都拿不到 → 返回 -1，日志写「已试过备用域名，分母暂用自数 N」，不再静默。
- 每个候选地址都会把 URL + 页面片段（或「页面里没有『已完成任务点』」）打进日志，
  下次真机一看就知道是哪一步不对。
- `cpi` 必须是账号里的真值；课程缓存里没有 cpi 会单打一行日志，不拿 `enc` 或 `0` 顶替。
